# Local Gallery for iOS

A private companion to Photos for iPhone: a local-first gallery that reads your photo library and
never sends anything anywhere. It is the iOS sibling of the Android Local Gallery app. The two apps
share privacy rules and file formats, not code.

On the home screen the app is called **Local Gallery**. App Store processing rejects the plain name "Gallery" as already taken (ITMS-90129), so the display name matches the App Store record.

## Privacy

Gallery has no networking code of its own, no account, no analytics and no crash-reporting SDK.
It does not upload photos, videos or metadata.

iOS has no network permission an app can give up, so the claim is backed by checks you can
inspect instead:
- **Every CI build** scans the app binary for networking frameworks and calls. The release
  build's scan is attached to each TestFlight upload's workflow run.
- **The privacy manifest** declares no tracking and no collected data.
- **App Privacy Report** (Settings → Privacy & Security) shows every domain an app contacted, so you
  can check Gallery yourself. It should list none.

TestFlight builds share crash reports with the developer through Apple. That is a system feature
outside Gallery's code.

## Status

**Slice 1:** a read-only timeline of the photos and videos iOS lets Gallery see, grouped by month.
It has designed screens for every access state:
- not yet asked
- full access
- limited (selected photos)
- denied
- restricted
- library unavailable
- empty
- items stored only in iCloud

Gallery never downloads iCloud originals.

## Building

There is no Mac in this project's loop. GitHub Actions builds and tests on hosted macOS runners
(`.github/workflows/ci.yml`). The platform-free `Core` package also runs on Linux:
`swift test --package-path Core`.

- `LocalGallery.xcodeproj` is generated by `scripts/gen_xcodeproj.py`. Never edit it by hand. Swift
  files added under `LocalGallery/` or `LocalGalleryTests/` are picked up automatically.
- Privacy gates run on every push: `scripts/lint_sources.py`, `check_dependencies.py`,
  `check_privacy_manifest.py`, `check_capabilities.py` and `scan_network_symbols.py`.
- TestFlight uploads: see `docs/testflight-setup.md`.
